  • 定时发布
用于保护定时访问地址与配额查询接口，泄露后可在此重置。
至
每天的几点几分生效，留空表示不限制；结束时间早于开始时间表示跨天（如 22:00 至 06:00）。
分钟
两次发布动作之间的最小间隔，由外部定时任务访问触发。
篇
每次执行最多发布多少篇隐藏内容（按 ID 升序）。
篇/天
由下方所有参与栏目「每日上限」自动汇总，栏目留空或为 0 表示不参与定时发布。

至
发布时随机写入的访问量区间。
将该地址加入服务器的计划任务（如 crontab），按发布间隔定期访问即可自动发布。
供外部系统调用，返回 JSON：daily_total（每日总量配额）、hidden_count（隐藏内容数量）。
提示：每日总量等于所有参与栏目每日上限之和；栏目留空或填写 0 表示不参与定时发布。定时任务只会发布已参与栏目中的隐藏内容，跨天自动重置当日计数。
